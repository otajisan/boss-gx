# 特徴 → パラメーターの対応表

`tools/analyze.py` が出す `features.json` の値を、GX のパラメーターに読み替えるためのルール。
使うたびに当たり外れを記録して育てる。**アンプ・スピーカーの対応は GX-1B の一覧がそろってから書く。**

## 特徴の読み方（ベース）

| 特徴 | 意味 | 気をつけること |
|---|---|---|
| `third_octave_db` | 1/3 オクターブごとのレベル（100Hz = 0dB） | **山と谷の位置を見る主な材料**。stem の高域は下の「目標の音の選び方」を見る |
| `bands_db` | 帯域ごとのエネルギー（全体に対する dB） | **demucs の stem では 5 kHz より上（`high`）が大きく削れる**（下の実測）。stem から測った `high` は EQ の判断に使わない |
| `brightness.centroid_hz` | 平均スペクトルの重心 | ベースは低域が大きいので数百 Hz になる。曲どうしで比べる |
| `distortion.upper_harmonic_db` | 4〜10 次 ÷ 1〜3 次の倍音 | 歪みの量の主な目安。大きいほど歪んでいる |
| `distortion.odd_even_ratio_db` | 奇数次 ÷ 偶数次 | 大きいほど対称なクリップ（ハードな歪み）寄り |
| `distortion.voiced_frames` | 基音が取れたフレームの数 | 少ないと歪みの値の信頼度が低い（和音・強い歪み・スラップなど） |
| `dynamics.range_p95_p10_db` | 鳴っているフレームの音量のばらつき | 小さいほど音量が揃っている（コンプが強い）。演奏の強弱も混ざる |
| `dynamics.decay_db_per_sec` | 音の減り方 | ゆるやかなほどサステインが長い（コンプ・歪みで伸びる） |
| `level.crest_factor_db` | ピーク ÷ RMS | 小さいほど潰れている（コンプ・歪み） |

### 2026-11-03: UNDEAD を考え直す（40〜55 秒スラップ、56〜67 秒指弾き）

1/3 オクターブで測った（100Hz を 0 dB）:

| 帯域 | スラップ | 指弾き |
|---|---|---|
| 31.5Hz | -8 | -10 |
| 50Hz | **+5** | **+4** |
| 250〜500Hz | -10〜-16 | -12〜-15 |
| 630Hz〜1.25kHz | **-17〜-19** | **-19〜-23** |
| 2.5kHz | **-7** | **-12** |
| 5〜10kHz | -11〜-14 | -16〜-18 |

→ **太いロー・深いミッドの谷・2.5kHz と高域が残る、ハイファイでモダンな音**。スラップと指弾きは同じ形で、2.5kHz より上が 5dB ほど違うだけ。

R1〜R3 が外れた理由（反省）:
- **中域を持ち上げていた（1kHz・2kHz +3）。実際は深い谷** → 形が逆
- 4 kHz で区切った帯域の平均（`bands_db`）だけ見ていて、谷と山の位置が見えていなかった。**ベースだけの音源があるときは 1/3 オクターブで形を見る**
- SVT（CONCERT）の歪み・強いコンプ・DYN57 で、ハイファイな音を潰していた
- 「うまくいったアンプ（CONCERT）を流用する」は、音のキャラクターが違う曲には効かない

R4（`output/rounds/r4-undead/`）: クリーンなアンプ、EQ で中域を深く削る、高域を活かすマイク（CND87）、コンプは軽く
- SLAP A: NATURAL gain 25、60/35/60 ＋ EQ（LOW CUT 31.5Hz、LOW +4、1kHz -7、HIGH +5）、X-COMP 4:1・DIRECT 40・ATTACK 70 / B: アンプを SW-TOUR に
- FINGER A: NATURAL gain 30、55/40/55 ＋ EQ（LOW CUT 31.5Hz、LOW +3、800Hz -6、HIGH +3）、X-COMP 3:1・DIRECT 50 / B: アンプを STUDIO に

結果（R4、ユーザー）: **スラップ・指弾きとも B がイメージに近い**（SW-TOUR / STUDIO）。音量がちょっと小さい → amp level 45→60、EQ level +3dB にして採用（`knowledge/tones/undead/`）

学び:
- 1/3 オクターブで形を見て EQ を決めたら、1 回で方向が合った
- ハイファイな音には SW-TOUR（スラップ）・STUDIO（指弾き）。NATURAL よりキャラクターがあるほうが近い
- EQ で大きく削る・コンプの DIRECT を上げると音量が下がる。amp level か EQ level で戻す（他のパッチとの音量差は、リアンプで測れるようにしたい）

### 2026-11-03: 目標の音の選び方（ベース＋ドラムの音源が追加された）

`input/<曲> - Bass.wav`（ベースとドラムだけ）が祝福・セブンティーンに追加された。曲全体と時間はそろっている（ずれ 0 ms）。tone-analyst が 3 つを比べた:
(a) 曲全体から取り出した stem / (b) ベース＋ドラムそのもの / (c) **ベース＋ドラムから取り出した stem**

- **(c) が一番きれい**。200Hz までは (a) と 1dB 以内で同じだが、(a) は**中域（400Hz〜1kHz）に他の楽器が漏れ込む**（セブンティーンの通常では (a) の 800Hz が (b) を超えていた＝ベースではあり得ない）。2.5kHz も (a) は他の楽器に隠れて削れていた（祝福の暗めで 5dB 差）
- **(b) はそのままでは目標に使えない**: 40〜80Hz はキック、250Hz より上はドラム、4kHz より上はシンバル（約 -46dBFS で平ら）が占める。ベースが勝つのは 125〜160Hz だけ
- **stem の高域**: ベース自身に高域があれば、stem でも**約 4kHz までは残る**（セブンティーンのスラップで (a)(b)(c) が 1〜3dB で一致）。5〜6.3kHz で急に落ちるのは分離の削れ。指弾きの暗い音では 3.15kHz より上は確かめようがない
- → compare.py の目標は (c)、**`--max-hz 3150`**（2.5kHz は ±5dB の幅で読む）。3.15kHz より上（HIGH CUT など）は耳で判断する
- 祝福・暗め（(c)、76〜96 秒）の形: 80〜160Hz が山（125Hz +3）、630Hz〜1kHz が深い谷（-38〜-43）、2.5kHz で -12 に持ち上がる。1:16〜1:28 はアクセントあり、1:28〜1:36 はより平らで暗い。暗めの区間は全体で約 75〜98 秒

### 2026-11-03: 訂正 — 祝福 1:16〜1:36 は「ジャキッとしたピック弾き」（ユーザー）

- これまで「丸い指弾き」と読んでいたのは誤り。stem では 3kHz より上が削れ、シンバルにも隠れるので、ピックのアタック（ジャキッ）が数値に出ず、暗く見えていた
- 採用した SHUKU DARK（HIGH CUT 5kHz で丸める）は、この読み違いのもとで作った候補の中で一番近かったもの。原曲に寄せるなら高域は残す方向を試す
- 学び: **stem で暗く見えても、弾き方（ピック／指／スラップ）はユーザーに確かめる**。弾き方は数値より耳のほうが確か。tone-analyze の出力に「弾き方の推定」と確認の問いを入れる

### 2026-11-03: Phase 2 の最初の実験（祝福・暗め＝ピック、目標 (c) 76〜96 秒、`--max-hz 3150`）

本人のピック弾きの DI（20 秒）を `shukufuku-final.tsl` の U01（BRIGHT）・U02（DARK）に通して compare した（`output/reamp/shuku-dark-r1/`）。**注意: この DI はベースのボリュームが下がった状態で録っていた（ユーザーが後で気づいた）。パッシブなら高域も落ちているので、帯域の値は参考程度**。

- **順位は耳と一致**: U02 距離 10.9 dB ＜ U01 16.9 dB → compare.py の距離は使える
- **低域の差は弾いた音の高さで決まる**: DI は中央 54Hz（G1〜A#1）、原曲は中央 40Hz（E1）・下は 37Hz（D1）。低域（40〜200Hz）の差はパッチではなくフレーズの違い。**DI は原曲と同じ音域（同じ音）で弾く**。原曲はドロップ D か 5 弦の可能性（未確認）
- **中域の谷がパッチで作れていない**: 800Hz は DI のままで +21.8、U02 で +22.0（パッチはほぼ削っていない）。630Hz〜1.25kHz を EQ で大きく削る方向（stem の谷は深めに出ることがあるので量は詰める。(b) から 800Hz は 100Hz より少なくとも 17dB 低い）
- **2.5kHz が足りない**（U02 -7.6）。3.15kHz は DI より 5dB 落ちている（HIGH CUT 5kHz・スピーカー）→ ピックのアタックを残す方向。ピック弾きの訂正と合う
- 音量: U02 は U01 より 5.9dB 小さい
- 読み方のこつ: **DI そのものも候補として compare に入れる**と、「パッチの前から違う所」（楽器・フレーズ）と「パッチが作った違い」を分けられる

### 2026-11-03: Phase 2 の 2 回目（祝福・明るめ＝ピック、目標 (c) 40〜52 秒、`--min-hz 100 --max-hz 3150`）

ボリューム全開のピック弾きの DI を U01 BRIGHT・U02 DARK に通した（`output/reamp/shuku-bright-r1/`）。ユーザーのベースは原曲の一番低い音（B）を弾けないので 100Hz 未満は外した（`compare.py --min-hz` を追加）。

- 距離: U02 DARK 7.36 ＜ DI 7.62 ＜ **U01 BRIGHT 10.25**（明るめ用の採用パッチが一番遠い）
- 3 つとも同じ向き: **630Hz〜1kHz が多い（+5〜+19）、2〜3.15kHz が足りない（-6〜-13）**。DI のままでも同じ形 → 本人のベースと原曲の差を、パッチで逆に補正する必要がある。U01 は EQ 800Hz +3・BASS DI で中域をさらに足していた（歪みも +7）
- **コンプが効きすぎ**: 減り方差 +27〜+28（目標より大幅に伸びる）、ばらつき差 -4〜-5。祝福の採用パッチは型紙のコンプ（12:1、DIRECT 0）のままだった
- 耳で選んだ BRIGHT 2 が数値では一番遠い → 耳で選んだのは「出した候補の中で一番近いもの」で、候補の方向自体がずれていた可能性

R5（`output/rounds/r5-shuku-bright-reamp/`、SHUKU BR R5 1〜4）: リアンプで順位を測ってから耳で確かめるので、方向の違う 4 案にした。共通: 800Hz を削る、HIGH・TREBLE で 2〜3.15kHz を足す、LOW +2〜3・bass 60〜65 で 160〜200Hz の不足を補う、gain 30（歪み +7 を減らす）、コンプは X-COMP 3:1〜4:1・DIRECT 50・ATTACK 60、音量は amp level 55・EQ level +2〜3 で戻す
- 1: BRIGHT の延長（STUDIO、DYN57、BASS DI drive 15 / direct 80、800Hz -8、HIGH +5）
- 2: EQ で深く（STUDIO middle 40 / treble 65、CND87、OD/DS なし、800Hz -14、HIGH +8）
- 3: HI BAND DRV（drive 30、direct 70）で高域だけ歪ませてピックのジャキッを足す（800Hz -10、HIGH +4、CND87）
- 4: アンプ違い SW-TOUR（middle 35 で中域を引っ込める、CND87、800Hz -8、HIGH +5）
- 見たいこと: 800Hz の削り量（-8 / -10 / -14）でどこまで差が縮むか、2〜3.15kHz を EQ・マイク・HI BAND DRV・アンプのどれで出すのが効くか、軽いコンプで減り方差 +27 がどこまで縮むか、音量が -20 dBFS 前後にそろうか

結果（R5、リアンプ＋耳。目標 (c) 40〜52 秒、`--min-hz 100 --max-hz 3150`、同じ DI。`output/reamp/shuku-bright-r1/compare-r5.json`）:
- 距離: **U04 SW-TOUR 5.06** ＜ U02 7.55 ＜ DI 7.62 ＜ U01 8.21 ＜ U03 10.16 ＜ 旧 BRIGHT 10.25
- **ユーザーの耳でも U04 が一番近い（数値と一致）**。ただし「ちょっと高音が強すぎて痛い」

学び:
- **compare の距離と耳の順位は 2 回続けて一致**。リアンプで絞ってから耳で確かめる流れでよい
- SW-TOUR（middle 35）は、ピックで中域を引っ込めて上を出したい音に合う（UNDEAD スラップに続き 2 曲目）
- 痛さは数値で見えない 3.15kHz より上から来る（HIGH +5・CND87・treble 60・HIGH CUT FLAT が重なった）。**`--max-hz 3150` の数値が良くても、4kHz より上の出しすぎは耳で確かめる**
- 2〜2.5kHz はまだ足りない。HI BAND DRV では出ない
- PARA.EQ の MID を 1 バンドで深く（-14）削ると、外側（315〜400Hz）が相対的に浮く
- コンプは 12:1・DIRECT 0 では効きすぎ（減り方差 +27）、4:1・DIRECT 50 では軽すぎ（-15.6）。間を探す

ユーザーの決定: **祝福は Bright/Dark で分けず、1 パッチで曲全体**（0:40〜0:52 も 1:16〜1:36 もピック弾き）。

R6（`output/rounds/r6-shukufuku/`、SHUKUFUKU R6 1〜3）: U04 から出発し、4kHz より上の抑え方だけを変えた 3 案。2〜2.5kHz は削らない
- 共通: X-COMP 4:1 のまま DIRECT 50→25（THRESHOLD の数字の向きは未確認なので触らない）、amp bass 65→70・EQ LOW +2→+1（200Hz を足し、100Hz は増やさない）、800Hz -8→-10（-14 の副作用を避けて少しだけ）、EQ level +2→+3（高域を抑えた分の音量を戻し、-16 dBFS 前後にそろえる）
- 1: EQ で切る。HIGH +5→+3、HIGH CUT 6.3kHz、2〜2.5kHz はアンプの treble 60→65 で残す
- 2: マイクを CND87→DYN421（高域が穏やか）。EQ HIGH +5・HIGH CUT FLAT・treble 60 は U04 のまま
- 3: アンプの treble 60→45 で上全体を下げ、EQ の HIGH +7 と HIGH CUT 5kHz を組み合わせて 2〜4kHz に山を作る
- 見たいこと: どの抑え方で 2〜2.5kHz（-7）を保ったまま痛さが消えるか、DIRECT 25 でばらつき差 +11・減り方差 -15.6 がどこまで縮むか、bass 70 で 200Hz（-7）が縮み 100Hz（+7）が増えないか、800Hz -10 で 315〜400Hz が浮かないか、0:40〜0:52 と 1:16〜1:36 の両方に合うか

結果（R6、ユーザーの耳）: **R6 の 3 案も R5-U04 も「全体的にまだ高音が耳に痛い」**。HIGH CUT 5kHz の案 3 でも痛い
- → 痛さは 4kHz より上だけでなく、**2〜4kHz（ピックのアタック）そのもの**にもある
- 中域を引っ込める SW-TOUR（middle 35）の方向は、数値でも耳でも一番近いので続ける
- 比べる区間をユーザーの希望で **0:06〜0:21**（ピック弾き）に変えた。1:16〜1:36 とほぼ同じ形: 630Hz〜1kHz が -34〜-41 の深い谷、2〜2.5kHz で -13〜-14 に持ち上がる。よく出る音は A1・G1・A#1・G#1 で、ユーザーも弾ける（`--min-hz` で外さなくてよい見込み）

学び:
- **セブンティーンのスラップ R1 と同じ**: 原曲の 2〜5kHz は「ミックスの中で抜けて聞こえる量」で、単体で弾くと痛い。リアンプの数値（2〜2.5kHz が目標より -7）に合わせ切ると単体では痛くなる → **2〜4kHz は数値より耳を優先し、目標より控えめにする**（compare の 2〜3.15kHz の不足はある程度残してよい）
- 高域を抑える手段を 1 つずつ（EQ だけ／マイクだけ／アンプだけ）試しても足りなかった。重ねて減らす必要がある

R7（`output/rounds/r7-shukufuku/`、SHUKUFUKU R7 1〜3）: R6-1 から出発し、高域を段階的に減らした 3 案。中域の谷（800Hz -10、middle 35）・低域（bass 70、LOW +1、LOW CUT 40Hz）・コンプ（X-COMP 4:1、DIRECT 25）・SW-TOUR gain 30・B4x10 は R6 のまま

祝福（R5〜R8）で固まった学び:
- **リアンプの距離は耳の順位と合う**（R5 で U04 が数値・耳とも 1 位）。候補が多いときは、先に数値で絞ってから耳で決める
- **原曲の 2〜3kHz は「ミックスの中で抜けて聞こえる量」**。単体で弾いて痛くないのは、目標より **4〜6dB 控えめ**（2〜3.15kHz の差が -9〜-11 くらい）。数値をゼロに合わせ切らない
- 3.15kHz より上（痛さの主な原因の一つ）は数値で見えない。抑えるのは マイク（RIBON121・DYN421）＋ HIGH CUT 4〜5kHz ＋ TREBLE を下げすぎない（40 だと 2〜3kHz まで削れる。48 くらい）
- **中域の出すぎは、アンプの MIDDLE を下げるほうが EQ の 1 バンドより素直に減る**（middle 35→25 で 800Hz〜1kHz が 3dB 減り、315〜400Hz は浮かなかった。EQ 800Hz -14 は 315〜400Hz を浮かせた）
- **高域を削った分の音量を amp level と EQ level の両方で戻すと行き過ぎて割れる**（R7-3 でピーク +1.6dBFS）。片方で +2〜3dB まで。リアンプの RMS で確かめる
- 本体に書き込まずに BTS で聞き比べていると、本体のパッチは前のまま（R8 の最初のリアンプで R7 の音を録ってしまった）。**リアンプの前に、本体のパッチ名を確かめる**
