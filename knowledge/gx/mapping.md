# 特徴 → パラメーターの対応表

`tools/analyze.py` が出す `features.json` の値を、GX のパラメーターに読み替えるためのルール。
使うたびに当たり外れを記録して育てる。**アンプ・スピーカーの対応は GX-1B の一覧がそろってから書く。**

## 特徴の読み方（ベース）

| 特徴 | 意味 | 気をつけること |
|---|---|---|
| `third_octave_db` | 1/3 オクターブごとのレベル（100Hz = 0dB） | **山と谷の位置を見る主な材料**。stem の高域は下の「目標の音の選び方」を見る |
| `bands_db` | 帯域ごとのエネルギー（全体に対する dB） | **demucs の stem では 5 kHz より上（`high`）が大きく削れる**（下の実測）。stem から測った `high` は EQ の判断に使わない |
| `brightness.centroid_hz` | 平均スペクトルの重心 | ベースは低域が大きいので数百 Hz になる。曲どうしで比べる |
| `distortion.upper_harmonic_db` | 4〜10 次 ÷ 1〜3 次の倍音 | 歪みの量の主な目安。大きいほど歪んでいる |
| `distortion.odd_even_ratio_db` | 奇数次 ÷ 偶数次 | 大きいほど対称なクリップ（ハードな歪み）寄り |
| `distortion.voiced_frames` | 基音が取れたフレームの数 | 少ないと歪みの値の信頼度が低い（和音・強い歪み・スラップなど） |
| `dynamics.range_p95_p10_db` | 鳴っているフレームの音量のばらつき | 小さいほど音量が揃っている（コンプが強い）。演奏の強弱も混ざる |
| `dynamics.decay_db_per_sec` | 音の減り方 | ゆるやかなほどサステインが長い（コンプ・歪みで伸びる） |
| `level.crest_factor_db` | ピーク ÷ RMS | 小さいほど潰れている（コンプ・歪み） |

### 2026-11-03: セブンティーン 0:20〜0:40（最初の手作りの下書き）

区間を 2 秒ずつ測ると、0:28 を境に 2〜5 kHz が約 30 dB 増える → **0:20〜0:28 が通常、0:28〜0:40 がスラップ**と判断。

| 特徴 | 通常 | スラップ |
|---|---|---|

| centroid_hz | 143 | 436 |
| range_p95_p10_db | 5.2 | 7.5 |
| decay_db_per_sec | -5.3 | -26.3 |
| crest_factor_db | 9.9 | 12.9 |
| upper_harmonic_db | -5.2 | -7.1 |

下書き（`output/セブンティーン/tone-*.json` → `seventeen.tsl`）の考え方:
- 通常: 暗く丸い・音量が揃う・長く伸びる・少し歪む → CONCERT（SVT）gain 45、treble 30、B8x10、DYN421、コンプ ON
- スラップ: 明るい・アタックが鋭い・短い → SW-TOUR（SWR）gain 30、bass 65 / middle 40 / treble 70、B4x10、CND87、コンプ ON
- 型紙の PARA.EQ・CHORUS は中身が不明なので OFF

結果（ユーザーが弾いた感想、R1）:
- 17 NORMAL: **モコモコしすぎて輪郭がない** → 外れ。treble 30・DYN421・B8x10 で暗くしすぎた
- 17 SLAP: **アタックが痛すぎる、ローが足りない** → 外れ。treble 70・CND87 で高域を出しすぎ、bass 65 では足りない

学び:
- **stem の「暗さ」をそのまま設定に写さない**。stem は他の楽器に隠れる分と分離で削れる分だけ、実際より暗く測れる。mid / high_mid が低くても、TREBLE・MIDDLE は中くらい（50 前後）から始める
- スラップの「2〜5 kHz が強い」は、原曲ではミックスの中で抜けて聞こえる量。単体で弾くと痛い。TREBLE は 50〜55 くらい、マイクは高域が穏やかなもの（DYN421・RIBON121）から
- スラップはローも欲しい（bass 75 前後）

R2（`seventeen-r2.tsl`）: U01 NORMAL A（bass 50 / middle 55 / treble 50、DYN57） / U02 NORMAL B（middle 60 / treble 60、B4x10） / U03 SLAP A（bass 75 / treble 55、DYN421） / U04 SLAP B（treble 50、B2x15、RIBON121）
結果（R2）: **NORMAL は A、SLAP は B がイメージに近い**（ユーザー）→ 採用。`knowledge/tones/seventeen/` に保存

採用した値から言えること（1 曲・1 人の耳。まだ仮のルール）:
- 指弾き・ピック（通常）: クリーン寄りのアンプ（CONCERT gain 45）で、bass 50 / middle 55 / treble 50 の平らに近い EQ、マイク DYN57。B（middle 60 / treble 60、B4x10）は行き過ぎ
- スラップ: SW-TOUR gain 30、bass 75 / middle 40 / treble 50（ローを足し、ミッドを少し下げ、高域は控えめ）、B2x15 + RIBON121 で高域の痛さを抑える

### 2026-11-03: 祝福（明るめ 0:40〜0:52・暗め 1:16〜1:36）と UNDEAD（0:16〜0:28）

| 特徴 | 祝福・明るめ | 祝福・暗め | UNDEAD（ベースだけの音源） |
|---|---|---|---|
| centroid_hz | 269 | 105 | 240 |

- 下書き（`output/rounds/r1-shukufuku-undead/`）: セブンティーンで当たった「ほぼ平らな EQ」から出発し、主にアンプの種類で A/B を作った
  - 祝福・明るめ: STUDIO / CONCERT、50/60/55
  - 祝福・暗め: FLIPTOP（B1x15）/ CLAS BLUE（B1x18）、60/50/45（暗さを写しすぎない）
  - UNDEAD: SOLID STK（CND87）/ CONCERT gain 50（DYN57）、55/50/60

結果（R1、ユーザー）: **祝福・明るめは A（STUDIO）、祝福・暗めは B（CLAS BLUE）だが歪みが強すぎる、UNDEAD は B（CONCERT）**。「EQ や OD/DS もうまく使ってほしい」

学び:
- CLAS BLUE は gain 35 でもはっきり歪む。クリーンにするなら 20 くらいから
- CONCERT（SVT）はセブンティーン NORMAL・UNDEAD の 2 曲で当たり。汎用の出発点にしてよい
- アンプと EQ（50 前後）だけでは物足りない。PARA.EQ（アンプの後ろ）と OD/DS（アンプの前）で仕上げる

R2（`output/rounds/r2-shukufuku-undead/`）: 当たったアンプはそのまま、EQ と OD/DS を足す
- 祝福・明るめ 1: STUDIO ＋ EQ（LOW CUT 40Hz、800Hz +3、HIGH +2） / 2: 1 ＋ BASS DI（drive 25、direct 70）
- 祝福・暗め 1: CLAS BLUE gain 20 ＋ EQ（LOW CUT 40Hz、250Hz -3） / 2: 1 ＋ LOW +3、HIGH CUT 5kHz
- UNDEAD 1: CONCERT gain 50 ＋ EQ（LOW CUT 40Hz、1kHz +3、HIGH +2） / 2: gain 40 ＋ SA DI DRIVE（drive 35、direct 60）＋ 同じ EQ

結果（R2、ユーザー）: **祝福・明るめは 2（BASS DI を薄く）、祝福・暗めは 2（LOW +3、HIGH CUT 5kHz）→ 採用**（`knowledge/tones/shukufuku/`）。**UNDEAD はどちらも音が潰れて抜けが悪い**

学び:
- OD/DS を direct 多め（70）で薄く足すと芯が出て良い（祝福・明るめ）
- 指弾きの丸い音は、アンプの高域ではなく EQ の HIGH CUT（5kHz）で丸めると良い（祝福・暗め）。アンプの TREBLE を下げてこもらせる（セブンティーン R1）のとは違う
- **型紙のコンプ（X-COMP、THRESHOLD 60、RATIO 12:1、DIRECT 0）はかなり強い**。ここまでの全パッチにかかっていた。歪み（gain 50）や中域の持ち上げと重なると潰れる
  - UNDEAD は原音がフルレンジで抜けている音なので、とくに目立った

R3（`output/rounds/r3-undead/`）: 潰れの原因を切り分ける
- 1: コンプを軽く（RATIO 4:1、DIRECT 50、ATTACK 60）、gain 35、EQ の持ち上げを 2kHz +3（抜け）・HIGH +3
- 2: 1 からコンプ OFF
- 3: 1 ＋ SA DI DRIVE ごく薄く（drive 20、direct 80）

結果（R3、ユーザー）: なかなかイメージに近づかない。「40〜67 秒を見て。前半スラップ、後半指弾き」

### 2026-11-03: UNDEAD を考え直す（40〜55 秒スラップ、56〜67 秒指弾き）

1/3 オクターブで測った（100Hz を 0 dB）:

| 帯域 | スラップ | 指弾き |
|---|---|---|
| 31.5Hz | -8 | -10 |
| 50Hz | **+5** | **+4** |
| 250〜500Hz | -10〜-16 | -12〜-15 |
| 630Hz〜1.25kHz | **-17〜-19** | **-19〜-23** |
| 2.5kHz | **-7** | **-12** |
| 5〜10kHz | -11〜-14 | -16〜-18 |

→ **太いロー・深いミッドの谷・2.5kHz と高域が残る、ハイファイでモダンな音**。スラップと指弾きは同じ形で、2.5kHz より上が 5dB ほど違うだけ。

R1〜R3 が外れた理由（反省）:
- **中域を持ち上げていた（1kHz・2kHz +3）。実際は深い谷** → 形が逆
- 4 kHz で区切った帯域の平均（`bands_db`）だけ見ていて、谷と山の位置が見えていなかった。**ベースだけの音源があるときは 1/3 オクターブで形を見る**
- SVT（CONCERT）の歪み・強いコンプ・DYN57 で、ハイファイな音を潰していた
- 「うまくいったアンプ（CONCERT）を流用する」は、音のキャラクターが違う曲には効かない

R4（`output/rounds/r4-undead/`）: クリーンなアンプ、EQ で中域を深く削る、高域を活かすマイク（CND87）、コンプは軽く
- SLAP A: NATURAL gain 25、60/35/60 ＋ EQ（LOW CUT 31.5Hz、LOW +4、1kHz -7、HIGH +5）、X-COMP 4:1・DIRECT 40・ATTACK 70 / B: アンプを SW-TOUR に
- FINGER A: NATURAL gain 30、55/40/55 ＋ EQ（LOW CUT 31.5Hz、LOW +3、800Hz -6、HIGH +3）、X-COMP 3:1・DIRECT 50 / B: アンプを STUDIO に

結果（R4、ユーザー）: **スラップ・指弾きとも B がイメージに近い**（SW-TOUR / STUDIO）。音量がちょっと小さい → amp level 45→60、EQ level +3dB にして採用（`knowledge/tones/undead/`）

学び:
- 1/3 オクターブで形を見て EQ を決めたら、1 回で方向が合った
- ハイファイな音には SW-TOUR（スラップ）・STUDIO（指弾き）。NATURAL よりキャラクターがあるほうが近い
- EQ で大きく削る・コンプの DIRECT を上げると音量が下がる。amp level か EQ level で戻す（他のパッチとの音量差は、リアンプで測れるようにしたい）

### 2026-11-03: 目標の音の選び方（ベース＋ドラムの音源が追加された）

`input/<曲> - Bass.wav`（ベースとドラムだけ）が祝福・セブンティーンに追加された。曲全体と時間はそろっている（ずれ 0 ms）。tone-analyst が 3 つを比べた:
(a) 曲全体から取り出した stem / (b) ベース＋ドラムそのもの / (c) **ベース＋ドラムから取り出した stem**

- **(c) が一番きれい**。200Hz までは (a) と 1dB 以内で同じだが、(a) は**中域（400Hz〜1kHz）に他の楽器が漏れ込む**（セブンティーンの通常では (a) の 800Hz が (b) を超えていた＝ベースではあり得ない）。2.5kHz も (a) は他の楽器に隠れて削れていた（祝福の暗めで 5dB 差）
- **(b) はそのままでは目標に使えない**: 40〜80Hz はキック、250Hz より上はドラム、4kHz より上はシンバル（約 -46dBFS で平ら）が占める。ベースが勝つのは 125〜160Hz だけ
- **stem の高域**: ベース自身に高域があれば、stem でも**約 4kHz までは残る**（セブンティーンのスラップで (a)(b)(c) が 1〜3dB で一致）。5〜6.3kHz で急に落ちるのは分離の削れ。指弾きの暗い音では 3.15kHz より上は確かめようがない
- → compare.py の目標は (c)、**`--max-hz 3150`**（2.5kHz は ±5dB の幅で読む）。3.15kHz より上（HIGH CUT など）は耳で判断する
- 祝福・暗め（(c)、76〜96 秒）の形: 80〜160Hz が山（125Hz +3）、630Hz〜1kHz が深い谷（-38〜-43）、2.5kHz で -12 に持ち上がる。1:16〜1:28 はアクセントあり、1:28〜1:36 はより平らで暗い。暗めの区間は全体で約 75〜98 秒

### 2026-11-03: 訂正 — 祝福 1:16〜1:36 は「ジャキッとしたピック弾き」（ユーザー）

- これまで「丸い指弾き」と読んでいたのは誤り。stem では 3kHz より上が削れ、シンバルにも隠れるので、ピックのアタック（ジャキッ）が数値に出ず、暗く見えていた
- 採用した SHUKU DARK（HIGH CUT 5kHz で丸める）は、この読み違いのもとで作った候補の中で一番近かったもの。原曲に寄せるなら高域は残す方向を試す
- 学び: **stem で暗く見えても、弾き方（ピック／指／スラップ）はユーザーに確かめる**。弾き方は数値より耳のほうが確か。tone-analyze の出力に「弾き方の推定」と確認の問いを入れる

### 2026-11-03: Phase 2 の最初の実験（祝福・暗め＝ピック、目標 (c) 76〜96 秒、`--max-hz 3150`）

本人のピック弾きの DI（20 秒）を `shukufuku-final.tsl` の U01（BRIGHT）・U02（DARK）に通して compare した（`output/reamp/shuku-dark-r1/`）。

- **順位は耳と一致**: U02 距離 10.9 dB ＜ U01 16.9 dB → compare.py の距離は使える
- **低域の差は弾いた音の高さで決まる**: DI は中央 54Hz（G1〜A#1）、原曲は中央 40Hz（E1）・下は 37Hz（D1）。低域（40〜200Hz）の差はパッチではなくフレーズの違い。**DI は原曲と同じ音域（同じ音）で弾く**。原曲はドロップ D か 5 弦の可能性（未確認）
- **中域の谷がパッチで作れていない**: 800Hz は DI のままで +21.8、U02 で +22.0（パッチはほぼ削っていない）。630Hz〜1.25kHz を EQ で大きく削る方向（stem の谷は深めに出ることがあるので量は詰める。(b) から 800Hz は 100Hz より少なくとも 17dB 低い）
- **2.5kHz が足りない**（U02 -7.6）。3.15kHz は DI より 5dB 落ちている（HIGH CUT 5kHz・スピーカー）→ ピックのアタックを残す方向。ピック弾きの訂正と合う
- 音量: U02 は U01 より 5.9dB 小さい
- 読み方のこつ: **DI そのものも候補として compare に入れる**と、「パッチの前から違う所」（楽器・フレーズ）と「パッチが作った違い」を分けられる
