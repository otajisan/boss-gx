# リアンプの設定（USB オーディオ）

## Mac での認識（2026-11-03 に確認）

- ドライバー: BOSS の「GX-1 Driver」（macOS）。入れると `/Library/Audio/Plug-Ins/HAL/RDUSB033CAudio.driver` ができる
  - 入れる前は USB 機器としては見えるが、オーディオデバイスに出てこない
- USB: ベンダー BOSS、製品番号 `0x033C`
- **GX-1B をつないでも、USB の製品名・オーディオデバイス名は「GX-1」になる**。名前で GX-1 と GX-1B を見分けられない（同じドライバーで動く）
  - 両方を同時につなぐ場合の見分け方は未確認

| 項目 | GX-1B | GX-1 |
|---|---|---|
| デバイス名（Core Audio） | GX-1 | 未確認 |
| 入力（GX → PC） | 4ch | 未確認 |
| 出力（PC → GX） | 4ch | 未確認 |
| 既定のサンプリング周波数 | 48000 Hz | 未確認 |

確かめ方: `uv run --with sounddevice python -I -m sounddevice`

## チャンネルの割り当て

### 入力（GX → PC）: GX-1B で実測（2026-11-03）

パッチを鳴らしながら 8 秒弾いて、4ch を録って比べた（録音は `output/channel-test/rec4ch.wav`）。

| ch | 中身 | 根拠 |
|---|---|---|
| 1-2 | **EFX**（処理後・ステレオ） | 2ch が少し違う（相関 0.94）。音量 -14.6 dBFS、重心 約 870 Hz |
| 3-4 | **DRY**（入力そのまま・モノ） | 3 と 4 が完全に同じ（相関 1.000）。EFX との相関は 0.08〜0.10。音量 -19.7 dBFS、重心 約 1030 Hz（アンプ・キャビを通っていないので高域が残る） |

→ リアンプの録音は ch1-2、DI の録音は ch3（3 と 4 は同じなので片方でよい）。
